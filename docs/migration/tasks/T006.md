## 6. Implementation instructions

1. Implement stable run/session/call keys plus argument digests, durable accepted/dispatched/running/terminal states and persisted result correlation.

2. Dispatch to T005 and reconcile handles after disconnect/restart. Return stored terminal result for duplicate delivery; reject conflicting args; unknown execution never automatically redispatches.

3. Forward cancellation to guest process groups and collect final statuses. Keep new target call IDs distinct from broker delivery retries.

4. Emit contracted tool events and expose results to host adapter/presentation consumers. Invalidate cached filesystem facts after arbitrary shell; service observations remain live.

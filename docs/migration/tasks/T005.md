## 6. Implementation instructions

1. Implement shell, read, filename/content search, write, exact edit and patch handlers using T001 contracts/native strategy. Pass command data through a defined API rather than interpolating host shells.

2. Resolve relative paths in guest cwd and follow guest symlinks normally. Preserve quoting, pipelines, encoding/BOM, limits, error wrappers and validate-before-mutation edit behavior.

3. Return command handles/status and stream output; support guest process-group cancellation. Persistent sessions/background jobs are disabled unless ownership and output are implemented.

4. Verify reads/searches, Git, Python and tests immediately observe the same file changes; HTTP clients execute normally. Do not implement cosmetic renderers in the worker.

## 7. Expected deliverables

Provide evidence files outside tracked large-data/log directories; never commit tokens or fetched bulk artifacts.

## 8. Acceptance criteria

AC1: All required handlers execute as the same UID in one guest state; native differential fixtures cover success and failure for edit/patch/read/search semantics.

AC2: Shell pipeline/redirection/exit/stdout/stderr behavior, binary/encoding handling, symlink/relative path handling and cancellation are independently tested.

AC3: No tool can choose a host path, container/run identity or service volume; unknown operations fail closed; disabled optional features are declared.
